Create a custom restaurant/cafe menu from WooCommerce categories with a fully coded AJAX menu page, fully isolated from your active theme.

== Description ==

Use `[wrmp_menu]` to render the menu or create a dedicated, standalone full-page menu from the plugin settings.

The plugin shows selected WooCommerce categories, loads products with AJAX, supports custom colors/logo/contact info, and includes Persian (`fa_IR`) language files.

The dedicated menu page renders on its own, without the active theme's header/footer, and dequeues the theme's and other plugins' frontend styles/scripts so nothing but this plugin's own layout and WooCommerce essentials can affect it.

== Installation ==

1. Upload the plugin to `/wp-content/plugins/`.
2. Activate WooCommerce.
3. Activate this plugin.
4. Configure settings under `Restaurant Menu`.
